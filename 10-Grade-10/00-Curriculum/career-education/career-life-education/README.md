**Languages:** Summary `en-CA`; primary standards reviewed in `en`. The English registry code is not an English-instruction requirement for every program. French reporting counterparts use the same CLE curriculum rather than a second repository record.

## Reporting options

The policy guide's printed p. 21 permits a single 4-credit course or two 2-credit parts. These are alternative reporting arrangements for one curriculum, not three courses to be completed together.

Use **CLE (4 credits)** or **CLEA + CLEB (2 + 2)** for English reporting, and **CLEF (4 credits)** or **CLEAF + CLEBF (2 + 2)** for the French counterparts. The table's TRAX and MyEducation BC identifiers are official reporting codes, distinct from this repository's record and learning-item IDs.

Administrative Grade 10 does not override the non-grade-designated delivery policy. Adult-only `CLE12` and `CLEF12` reporting is excluded.

Registry links use public `run-details.php` entry points, which establish a session and redirect to the detail view. If a viewer shows only a shell, use the public [Course Code Lookup](https://www.bced.gov.bc.ca/datacollections/course_registry_web_search/course-code-lookup.php), selecting TRAX and searching `CLE*` or an individual code. No session-specific URL or token is needed in repository links.
